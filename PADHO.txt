शुरू कैसे करें
──────────────

  Windows पर:   START.bat पर दो बार click करो.
  Linux पर:     terminal में  ./start.sh  चलाओ.

  बस इतना ही. कुछ install नहीं करना.


यह क्या है
──────────

  यह AI और मशीन लर्निंग सीखने का एक तरीक़ा है जो पूरी तरह
  तुम्हारे अपने computer पर चलता है.

  Internet की ज़रूरत नहीं — एक बार भी नहीं.
  कोई account नहीं, कोई password नहीं, कोई फ़ीस नहीं.
  तुम्हारा कोई data कहीं नहीं जाता.

  तुम code लिखोगे. वो चलेगा. जहाँ ग़लती होगी, वहाँ हिंदी में
  बताया जाएगा कि क्या गड़बड़ है और क्यों.


तीन बातें जो तुम्हें पता होनी चाहिए
────────────────────────────────────

  १. तुम्हारा laptop काफ़ी है.

     लोग कहते हैं AI सीखने के लिए महँगा computer चाहिए, GPU चाहिए.
     यह सच नहीं है.

     जो चीज़ें तुम यहाँ सीखोगे — रैखिक समाश्रयण, वर्गीकरण, निर्णय वृक्ष,
     छोटे तंत्रिका जाल — ये सब साधारण laptop पर चलती हैं. GPU तब चाहिए
     जब तुम बहुत बड़े model बनाओ. सीखने के लिए नहीं.

     जो laptop तुम्हारे पास है, उससे काम चल जाएगा.

  २. ग़लती करना ही सीखना है.

     जाँच फेल होना बुरा नहीं है. वही तो तरीक़ा है.
     हर बार फेल होने पर तुम्हें बताया जाएगा कि क्यों — और वही
     असल सीख है.

     जल्दी मत करो. एक पाठ में कई दिन लग सकते हैं. कोई गिन नहीं रहा.

  ३. तुम्हारा काम pen drive पर ही रहता है.

     जो code तुम लिखते हो, वो mera-kaam नाम के folder में
     अपने आप सहेजा जाता है — इसी pen drive पर.

     इसका मतलब: तुम्हारे पास अपना laptop न भी हो, तो college के lab
     के किसी भी computer पर pen drive लगाकर काम कर सकते हो. अगली बार
     किसी दूसरे computer पर बैठोगे, तो वहीं से आगे बढ़ोगे जहाँ छोड़ा था.


खिड़की में क्या है
──────────────────

  बाईं तरफ़   —  आज का पाठ. इसे पहले पढ़ो.
  दाईं तरफ़    —  यहाँ code लिखो.
  नीचे        —  चलाने या जाँचने के बाद का नतीजा.

  चलाओ  (F5)      code चलाकर दिखाता है. जब चाहो दबाओ,
                  प्रयोग करते रहो. print() लगाकर देखो कि
                  अंदर क्या हो रहा है.

  जाँचो           तुम्हारे code को परखता है और बताता है कि
                  क्या ठीक है, क्या नहीं.

  सहेजो (Ctrl+S)  काम बचाता है. वैसे यह अपने आप भी होता रहता है.

  सुराग़           अटक गए हो तो दबाओ. एक-एक करके इशारे मिलेंगे.
                  सारे एक साथ नहीं — क्योंकि सोचने का मौक़ा
                  छिन जाएगा.


अगर कुछ न चले
──────────────

  "Python नहीं मिला"
      pen drive में python नाम का folder होना चाहिए. copy करते
      वक़्त शायद छूट गया. पूरा folder दोबारा copy करो.

  हिंदी डिब्बों में दिख रही है
      तुम्हारे Windows में हिंदी font नहीं है.
      Control Panel → Region → Language में हिंदी जोड़ लो.

  app खुलकर तुरंत बंद हो जाती है
      mera-kaam folder में gadbad.txt नाम की file बनी होगी.
      वो अपने शिक्षक को दिखाओ.

  code चलाने पर कुछ नहीं होता
      शायद तुमने print() लगाया ही नहीं. Python चुपचाप हिसाब कर
      लेता है, दिखाता तभी है जब कहो.


किसी और को देना हो
